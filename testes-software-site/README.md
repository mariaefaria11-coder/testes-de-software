# QualityLab — Testes de Software

Site educacional responsivo com explicações, exemplos históricos e quiz interativo de 8 perguntas.

## Como executar
Abra `index.html` no navegador. Não precisa instalar nada.

## Como publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione **main** e **/(root)**, depois salve.
5. Aguarde a publicação e copie o link informado em Pages.

## Antes de entregar
Substitua “Integrante 1 e Integrante 2” no rodapé de `index.html` pelos nomes da dupla.

## Fontes de consulta
- ISTQB: https://www.istqb.org/
- U.S. GAO: https://www.gao.gov/
- UK National Audit Office: https://www.nao.org.uk/

Observação: os casos históricos envolvem problemas mais amplos de gestão e implantação, não apenas testes.
